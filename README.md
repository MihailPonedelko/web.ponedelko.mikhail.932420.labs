## Лабораторная работа №4

Изменения относительно ЛР №3, вариант 15 «Учёный и исследователь»:

- Подключён внешний файл `script.js`.
- Перед вводом измерений запрашивается имя через `prompt` и выводится приветствие через `alert`. Если имя не введено, используется «Исследователь».
- Добавлен ввод массива из 5–7 результатов измерений через `prompt`.
- Реализованы функции `findMax` для поиска максимума, `filterAboveAverage` для фильтрации значений строго выше среднего и `calculateSum` для подсчёта суммы.
- Добавлен цикл для поиска и подсчёта аномально низких значений — не больше 10% от максимума.
- Сразу после корректного ввода измерений через `alert` выводится: «Среднее значение – X, Y измерений – выше среднего».
- Через `console.log` один раз после ввода каждого нового массива выводятся аномально низкие значения и их количество.
- Добавлена проверка разброса: если разность максимума и минимума больше 50, в консоль выводится «Наблюдается высокая вариативность данных».
