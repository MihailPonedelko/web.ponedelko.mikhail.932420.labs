## Лабораторная работа №2

Изменения относительно ЛР №1:

- Создан и подключён внешний файл `style.css` с основным оформлением страницы.
- Добавлены CSS-переменные в `:root` для основной цветовой гаммы и шрифта.
- Оформлены шапка, основной блок, боковая панель, форма, кнопка и подвал.
- Добавлены три способа задания стилей:
  - внешний файл `style.css`;
  - внутренний блок `<style>` для цвета и тени заголовков;
  - inline-стиль `opacity: 0.9` для формы.
- Реализовано позиционирование: `static` для секции навыков, `relative` для секции проектов и `absolute` для бейджа варианта.
- Список проектов оформлен как набор карточек с внутренним свечением при наведении и изменением прозрачности при нажатии.
- Для блока `aside` реализован эффект матового стекла через полупрозрачный фон и `backdrop-filter: blur()`.
- Добавлены состояния интерактивных элементов: `:hover`, `:active`, `:focus`, `:visited`.
- Поля формы получили видимый контур при фокусе.
- Исправлены описание страницы и добавлен атрибут `alt` у изображения.
